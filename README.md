# IsraRecover — שחזור קבצים

תוכנת Windows חינמית לשחזור קבצים שנמחקו או אבדו מדיסק און קי, מכרטיס SD, מדיסק חיצוני ומדיסק פנימי — בעברית פשוטה.
היא קוראת את הכונן **בקריאה בלבד** ומחזירה את הקבצים עם השמות והתיקיות המקוריים כשאפשר.

## הורדה

בעמוד [Releases](https://github.com/bot-sync-up/israrecover/releases/latest):

- `IsraRecover-<גרסה>-setup.exe` — מתקין (קיצור בתפריט התחל, הסרה, שיוך קובצי `.rscan`).
- `IsraRecover-<גרסה>-portable.exe` — קובץ יחיד, בלי התקנה, כולל .NET 8 — מתאים להפעלה מדיסק און קי.
- `SHA256SUMS.txt` — לאימות ההורדה.

> אם הקבצים שרוצים לשחזר נמחקו מכונן C — עדיף להריץ את הקובץ הנייד מדיסק און קי, או להתקין בכונן אחר.

דרישות: Windows 10/11 x64 עם WebView2 Runtime (מותקן בכל Windows מעודכן). התוכנה מבקשת הרשאות מנהל כדי לקרוא
את הכונן ישירות; בלי הרשאות עדיין אפשר לפתוח תמונות כונן וסריקות שמורות.

## אחריות

התוכנה מסופקת כמות שהיא, ללא אחריות מכל סוג. השימוש בה — לרבות שחזור, תמונת כונן ותיקון כונן — הוא על אחריות
המשתמש בלבד. הקוד סגור; המאגר הזה מכיל רק את קובצי הגרסאות.
